Introduction aux Réseaux de Neurones (Deep Learning)

Résumé du notebook de cours Live Coding

1. Machine Learning vs Deep Learning

Paradigme

  • ML Classique : Extraction manuelle de features (Feature Engineering) → Algorithme (ex: Random Forest).
  • Deep Learning : Données brutes (pixels, texte) → Le réseau apprend LUI-MÊME les features (bords, formes, objets).

Quand utiliser le DL ?

Pour des données non-structurées (images, son, texte) et quand on a beaucoup de données (>100k exemples).

2. Le Perceptron et Fonctions d'Activation

Le Neurone Artificiel

z = W.X + b
a = activation(z)

Rôle du biais (b) : Déplacer la frontière de décision (évite qu'elle passe toujours par l'origine).

Fonctions d'Activation

Fonction Formule Usage Avantages/Inconvénients
Sigmoid σ(z) = 1 / (1 + e⁻ᶻ) Sortie (Proba 0-1) ⚠️ Vanishing Gradient (dérivée nulle si z grand)
ReLU max(0, z) Couches Cachées ✅ Pas de Vanishing Gradient pour z>0, Calcul rapide
Tanh (eᶻ - e⁻ᶻ) / (eᶻ + e⁻ᶻ) Cachées (rare) Centrée en 0, mais Vanishing Gradient

3. Réseaux Fully Connected (Dense)

Chaque neurone d'une couche est connecté à tous les neurones de la couche suivante.

Dimensions

Input X: (n₀, m)
Poids W: (nₗ, nₗ₋₁)
Biais b: (nₗ, 1)
Sortie A: (nₗ, m)

4. Forward & Cost Function

Forward Propagation

Calcul des prédictions couche par couche de gauche à droite.

Z = W.A_prev + b
A = g(Z)

Fonction de Coût (Binary Cross-Entropy)

Mesure l'erreur entre la prédiction et la vraie valeur.

L = -1/m * Σ [y.log(ŷ) + (1-y).log(1-ŷ)]

5. Backpropagation (Cœur du DL)

Principe

Calculer le gradient de l'erreur par rapport à chaque poids (∂L/∂W) en remontant de la fin vers le début (Chain Rule).

Algorithme

  1. Calculer dZ (Erreur à la couche L)
  2. Calculer dW, db (Gradients des paramètres)
  3. Propager l'erreur à la couche précédente (dA_prev)

But : Savoir comment modifier W et b pour diminuer l'erreur.

6. Gradient Descent (Optimisation)

Mise à jour des paramètres

W = W - α . dW
b = b - α . db

Learning Rate (α) : Contrôle la vitesse d'apprentissage.

  • Trop grand : Divergence (l'erreur augmente)
  • Trop petit : Convergence très lente

7. Initialisation des Paramètres

⚠️ Ne jamais initialiser à ZÉRO ! (Sinon tous les neurones apprennent la même chose = Symétrie).

  • He Initialization : Optimisée pour ReLU (random * sqrt(2/n)).
  • Xavier Initialization : Optimisée pour Sigmoid/Tanh.

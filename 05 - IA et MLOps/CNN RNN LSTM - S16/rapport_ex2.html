1. Contexte

CIFAR-10 est un dataset de 60,000 images couleurs (32x32) réparties en 10 classes (avion, voiture, oiseau, chat, cerf, chien, grenouille, cheval, bateau, camion). C'est un défi plus complexe que MNIST car les images sont naturelles et variées.

4. Modèle Simple (CNN)

Nous avons d'abord testé une architecture simple avec 3 blocs de convolution/pooling.

def build_cnn_cifar10_simple():
    model = models.Sequential([
        layers.Input(shape=(32, 32, 3)),

        # Bloc 1
        layers.Conv2D(32, (3, 3), padding='same'),
        layers.BatchNormalization(),
        layers.Activation('relu'),
        layers.MaxPooling2D((2, 2)),

        # Bloc 2
        layers.Conv2D(64, (3, 3), padding='same'),
        layers.BatchNormalization(),
        layers.Activation('relu'),
        layers.MaxPooling2D((2, 2)),

        # Bloc 3
        layers.Conv2D(128, (3, 3), padding='same'),
        layers.BatchNormalization(),
        layers.Activation('relu'),
        layers.MaxPooling2D((2, 2)),

        layers.Flatten(),
        layers.Dense(256, activation='relu'),
        layers.Dropout(0.4),
        layers.Dense(128, activation='relu'),
        layers.Dropout(0.3),
        layers.Dense(10, activation='softmax')
    ])

    model.compile(optimizer=keras.optimizers.Adam(learning_rate=0.001),
                  loss='sparse_categorical_crossentropy',
                  metrics=['accuracy'])
    return model

5. Augmentation de Données

Pour combattre le surapprentissage, nous avons utilisé l'augmentation de données.

def create_data_augmentation():
    data_augmentation = keras.Sequential([
        layers.RandomFlip("horizontal"),
        layers.RandomRotation(0.1),
        layers.RandomTranslation(0.1, 0.1),
        layers.RandomZoom(0.2),
    ])
    return data_augmentation

6. Modèle Complexe & Entraînement Final

Nous avons ensuite utilisé un modèle plus profond et entraîné avec l'augmentation de données.

def build_cnn_cifar10_complex():
    model = models.Sequential([
        layers.Input(shape=(32, 32, 3)),

        # Bloc 1 (Double Conv)
        layers.Conv2D(64, (3, 3), padding='same', activation='relu'),
        layers.BatchNormalization(),
        layers.Conv2D(64, (3, 3), padding='same', activation='relu'),
        layers.BatchNormalization(),
        layers.MaxPooling2D((2, 2)),
        layers.Dropout(0.25),

        # Bloc 2 (Double Conv)
        layers.Conv2D(128, (3, 3), padding='same', activation='relu'),
        layers.BatchNormalization(),
        layers.Conv2D(128, (3, 3), padding='same', activation='relu'),
        layers.BatchNormalization(),
        layers.MaxPooling2D((2, 2)),
        layers.Dropout(0.25),

        # Bloc 3 (Double Conv)
        layers.Conv2D(256, (3, 3), padding='same', activation='relu'),
        layers.BatchNormalization(),
        layers.Conv2D(256, (3, 3), padding='same', activation='relu'),
        layers.BatchNormalization(),
        layers.MaxPooling2D((2, 2)),
        layers.Dropout(0.25),

        layers.Flatten(),
        layers.Dense(512, activation='relu'),
        layers.Dropout(0.5),
        layers.Dense(256, activation='relu'),
        layers.Dropout(0.4),
        layers.Dense(10, activation='softmax')
    ])

    model.compile(optimizer=keras.optimizers.Adam(learning_rate=0.001),
                  loss='sparse_categorical_crossentropy',
                  metrics=['accuracy'])
    return model

8. Réponses aux Questions

1. Batch Normalization améliore-t-elle la convergence ?

Oui. La Batch Normalization normalise les activations de chaque couche, ce qui stabilise le gradient et permet d'utiliser un learning rate plus élevé sans divergence. Cela accélère la convergence (moins d'epochs pour atteindre une bonne performance) et réduit la sensibilité du modèle à l'initialisation des poids. Dans notre modèle simple, cela aide à atteindre 75% d'accuracy rapidement.

2. Quel impact a l'augmentation de données sur l'overfitting ?

Elle le réduit considérablement. Sur le modèle simple (sans augmentation), on observe un fort overfitting : l'accuracy d'entraînement monte à 88.5% alors que celle de validation stagne autour de 73-75%. Cet écart ("gap") montre que le modèle apprend par cœur. L'augmentation de données (rotations, flips, zooms) force le modèle à apprendre des caractéristiques invariantes et généralisables, réduisant cet écart.

3. Quelles classes sont confondues ? Pourquoi ?

D'après le rapport de classification (f1-score) :

  • Classes les plus confondues : Chat (Cat) (f1=0.57) et Chien (Dog) (f1=0.67), ainsi que Oiseau (Bird) (f1=0.68).
  • Pourquoi : Ces classes partagent des caractéristiques visuelles très proches (fourrure, quatre pattes, oreilles, queue, arrière-plans naturels variés).
  • Classes bien prédites : Grenouille (Frog), Camion (Truck), Automobile (f1 > 0.85) car elles ont des formes distinctives et rigides (véhicules) ou des couleurs/postures spécifiques (grenouille).

4. Comment pourriez-vous améliorer davantage la performance ?

  • Architecture plus profonde : Utiliser des réseaux résiduels (ResNet) pour éviter la dégradation du gradient.
  • Transfer Learning : Utiliser un modèle pré-entraîné sur ImageNet (ex: MobileNetV2, ResNet50) comme vu dans l'Exercice 3.
  • Learning Rate Schedule : Réduire le taux d'apprentissage quand la loss stagne (ReduceLROnPlateau).
  • Regularisation avancée : Augmenter le Dropout ou utiliser le Weight Decay.

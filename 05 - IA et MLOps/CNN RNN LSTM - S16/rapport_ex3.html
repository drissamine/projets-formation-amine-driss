1. Contexte

Le Transfer Learning consiste à utiliser un modèle pré-entraîné sur un très grand dataset (ImageNet) pour résoudre une nouvelle tâche. Nous utilisons ici MobileNetV2.

2. Architecture du Modèle

def build_transfer_learning_model(freeze_base=True):
    # Charger MobileNetV2 (sans la tête de classification)
    base_model = keras.applications.MobileNetV2(
        input_shape=(32, 32, 3),
        include_top=False,
        weights='imagenet'
    )

    if freeze_base:
        base_model.trainable = False

    # Ajouter notre propre tête de classification
    model = models.Sequential([
        base_model,
        layers.GlobalAveragePooling2D(),
        layers.Dense(256, activation='relu'),
        layers.Dropout(0.3),
        layers.Dense(10, activation='softmax')
    ])

    model.compile(optimizer=keras.optimizers.Adam(learning_rate=0.001),
                  loss='sparse_categorical_crossentropy',
                  metrics=['accuracy'])

    return model, base_model

Conclusion

Le Transfer Learning permet généralement de converger beaucoup plus vite et d'obtenir de bons résultats même avec moins de données, car le modèle "sait" déjà extraire des caractéristiques visuelles complexes (bords, textures, formes).

6. Réponses aux Questions

1. Pourquoi le transfer learning converge-t-il plus rapidement ?

Le modèle (ici MobileNetV2) a déjà appris des extracteurs de caractéristiques robustes (bords, textures, formes complexes) sur un jeu de données massif (ImageNet). Au lieu de partir de poids aléatoires qui ne "savent" rien voir, on part d'un réseau qui sait déjà "voir". On n'a plus qu'à entraîner la dernière couche pour associer ces caractéristiques aux nouvelles classes, ce qui est une tâche d'optimisation beaucoup plus simple et rapide.

2. Qu'apprend le réseau dans les couches profondes d'ImageNet ?

Dans les CNNs, les premières couches apprennent des caractéristiques de bas niveau (lignes, coins, dégradés). Les couches profondes, elles, combinent ces éléments pour reconnaître des concepts sémantiques complexes et abstraits (ex: "œil", "roue", "texture de fourrure", "motif géométrique"). Ce sont ces concepts riches qui sont réutilisés pour classifier nos nouvelles images.

3. Quel est l'impact du fine-tuning progressif sur la performance ?

Le fine-tuning (dégeler les dernières couches du modèle de base) permet d'adapter légèrement les caractéristiques de haut niveau aux spécificités de notre nouveau dataset (CIFAR-10). Cela améliore généralement la précision finale car le modèle ne se contente plus de caractéristiques génériques ImageNet, mais affine sa perception pour différencier spécifiquement nos classes (ex: différencier un "camion" CIFAR-10 d'une "voiture" CIFAR-10).

4. Vaut-il toujours la peine d'utiliser transfer learning ?

Presque toujours, surtout si le dataset cible est petit ou moyen (< 1 million d'images). Cela économise énormément de ressources de calcul et de temps.

Exceptions :

  • Si le dataset cible est très différent visuellement (ex: imagerie médicale, images satellite infrarouge) vs images naturelles (ImageNet), les caractéristiques apprises peuvent être inutiles voire nuisibles.
  • Si on a un dataset immense et beaucoup de temps, un modèle entraîné "from scratch" peut parfois être plus optimisé pour la tâche spécifique.

Guide d'utilisation Kaggle

TP Réseaux de Neurones Convolutifs (CNN) & Transfer Learning

Ce guide vous accompagne étape par étape pour importer, configurer et exécuter le notebook TP_CNN.ipynb sur la plateforme Kaggle en utilisant l'accélération GPU gratuite.

1Prérequis

Avant de commencer, vous aurez besoin de :

  • Un compte sur Kaggle.com (Gratuit).
  • Le fichier TP_CNN.ipynb téléchargé sur votre ordinateur.
Note : Kaggle offre gratuitement environ 30 heures de GPU T4 x2 par semaine, ce qui est idéal pour ce TP.

2Création et Importation

  1. Connectez-vous à Kaggle.
  2. Naviguez vers la section "Code" dans le menu de gauche.
  3. Cliquez sur le bouton "New Notebook".
  4. Une fois l'éditeur ouvert, allez dans le menu File (en haut à gauche) > Import Notebook.
  5. Sélectionnez le fichier TP_CNN.ipynb depuis votre ordinateur.

Le contenu du notebook va charger et remplacer le notebook vide par défaut.

3Configuration Critique (GPU & Internet)

Pour que le code fonctionne correctement (surtout pour l'entraînement des CNN et le téléchargement des datasets), vous devez configurer ces deux options :

1. Activer le GPU

Essentiel pour la vitesse d'entraînement.

  • Ouvrez le panneau de droite (cliquez sur la flèche si masqué).
  • Cherchez la section Session options.
  • Changez Accelerator de "None" vers "GPU T4 x2".

2. Activer Internet

Requis pour télécharger MNIST/CIFAR-10/MobileNetV2.

  • Toujours dans Session options.
  • Localisez l'option Internet.
  • Basculez le switch sur "On".
Important : Si vous n'activez pas Internet, les commandes comme keras.datasets.cifar10.load_data() échoueront avec une erreur de connexion.

4Exécution du Notebook

Une fois configuré, vous pouvez lancer l'exécution :

  • Cliquez sur "Run All" pour tout exécuter d'un coup.
  • Ou exécutez cellule par cellule avec Shift + Enter.

Le notebook est structuré pour télécharger automatiquement les données nécessaires :

  • MNIST : ~11 MB
  • CIFAR-10 : ~170 MB
  • MobileNetV2 (ImageNet weights) : ~16 MB

5Sauvegarde et Export

Après avoir terminé le TP ou pour sauvegarder votre progression :

  • Utilisez le bouton "Save Version" en haut à droite.
  • Choisissez "Quick Save" pour sauvegarder l'état actuel.
  • Choisissez "Save & Run All" pour générer une version propre exécutée de A à Z (utile pour le rendu final).
  • Pour récupérer le fichier .ipynb modifié : Menu File > Download Notebook.

Dépannage Rapide

Erreur "Out of Memory (OOM)"

Si vous rencontrez une erreur de mémoire GPU :

  • Redémarrez le kernel (icône de flèche circulaire en haut).
  • Réduisez la taille du batch (batch_size=16 au lieu de 32).
  • Assurez-vous de ne pas avoir lancé plusieurs entraînements lourds simultanément en mémoire.
Erreur de téléchargement "Connection refused"

Vérifiez que l'option Internet On est bien activée dans le panneau de droite. C'est la cause n°1 des problèmes sur Kaggle pour ce TP.

3. Exercice 1 - Sélection de couleur par masque HSV

Objectif : Utiliser l'espace colorimétrique HSV pour isoler des couleurs spécifiques.

Contexte théorique

L'espace HSV (Hue, Saturation, Value) sépare la teinte (H), la saturation (S) et la luminosité (V). Cela facilite la sélection de couleurs car on peut filtrer sur une gamme de teintes spécifique.

Code utilisé :

# Conversion en HSV
hsv = cv2.cvtColor(img, cv2.COLOR_RGB2HSV)

# Définition des plages HSV pour le bleu
lower_blue = np.array([100, 50, 50])
upper_blue = np.array([130, 255, 255])

# Création du masque
mask = cv2.inRange(hsv, lower_blue, upper_blue)

# Application du masque
result = cv2.bitwise_and(img, img, mask=mask)

Plages HSV couramment utilisées :

Couleur Lower (H,S,V) Upper (H,S,V)
Rouge (0, 100, 100) (10, 255, 255)
Vert (40, 100, 100) (80, 255, 255)
Bleu (100, 100, 100) (130, 255, 255)
Jaune (20, 100, 100) (30, 255, 255)

4. Exercice 2 - Égalisation d'histogramme manuelle

Objectif : Implémenter l'égalisation d'histogramme sans utiliser cv2.equalizeHist.

Contexte théorique

L'égalisation d'histogramme vise à répartir uniformément les intensités sur tout l'intervalle [0, 255], améliorant le contraste全局.

Fonction implémentée :

def equalize_histogram_manual(img_gray): """Égalisation d'histogramme manuelle (sans cv2.equalizeHist)""" # 1. Calculer l'histogramme hist, bins = np.histogram(img_gray.ravel(), bins=256, range=(0, 256)) # 2. Calculer la CDF (Cumulative Distribution Function) cdf = hist.cumsum() # 3. Normaliser la CDF cdf_normalized = cdf * 255 / cdf[-1] # 4. Créer la table de lookup cdf_m = np.ma.masked_equal(cdf, 0) cdf_m = (cdf_m - cdf_m.min()) * 255 / (cdf_m.max() - cdf_m.min()) cdf = np.ma.filled(cdf_m, 0).astype('uint8') # 5. Appliquer la transformation img_equalized = cdf[img_gray] return img_equalized

Formule utilisée :

Pour chaque intensité i : nouvelle_intensité = (CDF(i) - CDF_min) × (L-1) / (M×N - CDF_min)

où L=256, M×N = nombre de pixels

5. Exercice 3 - CLAHE : trouver les bons hyperparamètres

Objectif : Tester différents paramètres de CLAHE (Contrast Limited Adaptive Histogram Equalization).

Contexte théorique

CLAHE diffère de l'égalisation globale en appliquant l'égalisation sur des tuiles locales, avec une limite de contraste pour éviter l'amplification du bruit.

Fonction utilisée :

def apply_clahe(img, clip_limit=2.0, tile_size=(8,8)):
    """Applique CLAHE sur le canal L de l'espace LAB"""
    clahe = cv2.createCLAHE(clipLimit=clip_limit, tileGridSize=tile_size)
    return clahe.apply(img)

Paramètres à tester :

Paramètre Effet Valeurs testées
clipLimit Limite le contraste pour éviter le bruit 1.0, 2.0, 3.0, 5.0
tileSize Taille des tuiles pour l'égalisation locale (4,4), (8,8), (16,16)

Recommandations :

  • clipLimit=2.0 : Bon compromis entre amélioration du contraste et contrôle du bruit
  • tileSize=(8,8) : Standard pour la plupart des images

7. Exercice 5 - Non-Local Means

Objectif : Comprendre l'effet des paramètres de Non-Local Means Denoising.

Contexte théorique

NLM compare des patchs similaires dans toute l'image pour réduire le bruit tout en préservant les détails.

Fonction :

result = cv2.fastNlMeansDenoisingColored(img, None, h, hForColorComponents, templateWindowSize, searchWindowSize)

Paramètres :

Paramètre Description Effet
h Force du débruitage Plus élevé = plus de débruitage, plus flou
templateWindowSize Taille de la fenêtre modèle Doit être impair (7 par défaut)
searchWindowSize Taille de la fenêtre de recherche Doit être impair, plus grand = plus lent

Recommandations :

  • h=3-5 : Pour bruit léger
  • h=10-15 : Pour bruit modéré
  • searchWindowSize=21 : Bon compromis qualité/vitesse

8. Exercice 6 - Letterbox avec informations

Objectif : Redimensionner en conservant le ratio (letterbox) et retourner les paramètres de transformation.

Fonctions implémentées :

letterbox_with_info()

def letterbox_with_info(img, target_size=(128, 128), pad_color=(114, 114, 114)): """ Redimensionne en conservant le ratio (letterbox). Retourne (img_resized, scale, off_x, off_y) """ h, w = img.shape[:2] target_w, target_h = target_size # 1. Calculer le facteur d'échelle et les nouvelles dimensions scale = min(target_w / w, target_h / h) new_w = int(w * scale) new_h = int(h * scale) # 2. Redimensionner resized = cv2.resize(img, (new_w, new_h), interpolation=cv2.INTER_LINEAR) # 3. Créer le canvas et calculer les offsets canvas = np.full((target_h, target_w, 3), pad_color, dtype=np.uint8) off_x = (target_w - new_w) // 2 off_y = (target_h - new_h) // 2 canvas[off_y:off_y+new_h, off_x:off_x+new_w] = resized return canvas, scale, off_x, off_y

to_original_coords()

def to_original_coords(x_r, y_r, scale, off_x, off_y): """Convertit des coordonnées dans l'image letterboxée vers l'image originale.""" x_orig = (x_r - off_x) / scale y_orig = (y_r - off_y) / scale return int(x_orig), int(y_orig)

10. Exercice 8 - Simulation de conditions météorologiques

Objectif : Implémenter les effets brume et pluie.

Fonctions :

add_fog()

def add_fog(img, intensity=0.5): """Simule de la brume en mélangeant avec un fond blanc.""" fog_layer = np.ones_like(img) * 255 return np.clip((1-intensity)*img.astype(np.float32) + intensity*fog_layer, 0, 255).astype(np.uint8)

add_rain()

def add_rain(img, num_drops=600, angle=-70, length=18, alpha=0.65): """Simule la pluie avec des traits diagonaux semi-transparents.""" rain_layer = np.zeros_like(img) h, w = img.shape[:2] for _ in range(num_drops): x1 = np.random.randint(0, w) y1 = np.random.randint(0, h) x2 = int(x1 + length * np.cos(np.radians(angle))) y2 = int(y1 + length * np.sin(np.radians(angle))) cv2.line(rain_layer, (x1, y1), (x2, y2), (200, 200, 220), 1) return np.clip(alpha*img + (1-alpha)*rain_layer, 0, 255).astype(np.uint8)

11. Exercice 9 - Mixup & CutMix

Objectif : Implémenter les techniques d'augmentation modernes.

Fonctions :

mixup()

def mixup(img1, img2, alpha=0.4): """Mélange linéaire de deux images.""" lam = np.random.beta(alpha, alpha) mixed = np.clip(lam*img1.astype(np.float32) + (1-lam)*img2.astype(np.float32), 0, 255).astype(np.uint8) return mixed, lam

cutmix()

def cutmix(img1, img2, alpha=1.0): """Colle un rectangle de img2 dans img1.""" lam = np.random.beta(alpha, alpha) h, w = img1.shape[:2] cut_w = int(w * np.sqrt(1 - lam)) cut_h = int(h * np.sqrt(1 - lam)) cx = np.random.randint(w); cy = np.random.randint(h) x1 = max(cx - cut_w//2, 0); x2 = min(cx + cut_w//2, w) y1 = max(cy - cut_h//2, 0); y2 = min(cy + cut_h//2, h) result = img1.copy() result[y1:y2, x1:x2] = img2[y1:y2, x1:x2] lam_real = 1 - (x2-x1)*(y2-y1) / (h*w) return result, lam_real

12. Exercice 10 - Pipeline étendu

Objectif : Ajouter CLAHE et CutOut au pipeline existant.

EnhancedPipeline :

class EnhancedPipeline(ImagePreprocessingPipeline): def __init__(self, *args, use_clahe=True, cutout_holes=1, cutout_size=40, **kwargs): super().__init__(*args, **kwargs) self.use_clahe = use_clahe self.cutout_holes = cutout_holes self.cutout_size = cutout_size def _apply_clahe(self, img, clip_limit=2.0): """Applique CLAHE sur le canal L de l'espace LAB.""" lab = cv2.cvtColor(img, cv2.COLOR_RGB2LAB) clahe = cv2.createCLAHE(clipLimit=clip_limit, tileGridSize=(8,8)) lab[:,:,0] = clahe.apply(lab[:,:,0]) return cv2.cvtColor(lab, cv2.COLOR_LAB2RGB) def _cutout(self, img): """Masque n_holes carrés de taille cutout_size en noir.""" h, w = img.shape[:2] result = img.copy() for _ in range(self.cutout_holes): cx = np.random.randint(w); cy = np.random.randint(h) s = self.cutout_size x1 = max(cx - s//2, 0); x2 = min(cx + s//2, w) y1 = max(cy - s//2, 0); y2 = min(cy + s//2, h) result[y1:y2, x1:x2] = 0 return result

13. Exercice 11 - Diagnostic automatique

Objectif : Système complet de diagnostic et correction d'images.

Fonctions :

diagnose()

def diagnose(img): """Diagnostique les problèmes d'une image.""" gray = (0.2126*img[:,:,0] + 0.7152*img[:,:,1] + 0.0722*img[:,:,2]) issues = [] if gray.mean() < 80: issues.append("sous_expose") if gray.mean() > 180: issues.append("sur_expose") if gray.std() < 30: issues.append("faible_contraste") lap_var = cv2.Laplacian(gray.astype(np.uint8), cv2.CV_64F).var() if lap_var < 50: issues.append("bruite") stats = {"mean": gray.mean(), "std": gray.std(), "lap_var": lap_var} return issues, stats

auto_correct()

def auto_correct(img, issues): """Applique les corrections adaptées.""" result = img.copy() if "sous_expose" in issues or "sur_expose" in issues: result = apply_clahe(result) if "bruite" in issues: result = cv2.bilateralFilter(result, 9, 75, 75) if "faible_contraste" in issues: result = normalize_percentile(result) return result

Indicateurs :

Problème Indicateur Seuil
Sous-exposition Moyenne globale < 80
Surexposition Moyenne globale > 180
Faible contraste Écart-type global < 30
Bruit excessif Variance du Laplacien < 50

🚀 Guide d'Utilisation

Pipeline de Streaming Analytics avec Kafka et Spark

EEnvironnement & Prérequis

Avant de commencer, assurez-vous d'avoir installé les outils suivants :

  • Java 8+ (Requis pour Kafka et Spark)
  • Python 3.9+
Installation des dépendances Python :
Ouvrez un terminal à la racine du projet et exécutez les commandes suivantes : 
pip install -r producer/requirements.txt
pip install -r spark/consumer/requirements.txt
pip install -r web/requirements.txt

1Démarrer l'Infrastructure (Kafka)

Nous devons d'abord lancer ZooKeeper et Kafka qui géreront le flux de messages.

Lancement des serveurs

Exécutez le script suivant (double-cliquez ou lancez via terminal) : 

kafka\start_kafka.bat

⚠️ Important : Deux nouvelles fenêtres vont s'ouvrir (ZooKeeper et Kafka). Ne les fermez pas ! Laissez-les tourner en arrière-plan.

Création du Topic

Une fois Kafka démarré, créez le topic qui recevra les données (à faire une seule fois) : 

kafka\create_topic.bat

2Lancer le Tableau de Bord

Démarrez l'interface web pour visualiser les données en temps réel.

Ouvrez un nouveau terminal à la racine du projet : 

python web/dashboard.py

Ouvrez votre navigateur à l'adresse : http://localhost:5000

3Démarrer le Traitement Spark

Lancez le job Spark qui va consommer les données de Kafka et les analyser.

Ouvrez un nouveau terminal à la racine du projet : 

python spark/consumer/spark_streaming_app.py

Vous verrez des logs indiquant que Spark traite des "Batchs".

4Générer des Données (Producteur)

Enfin, lancez le producteur pour simuler l'activité des utilisateurs.

Ouvrez un nouveau terminal à la racine du projet : 

python producer/kafka_producer.py --continuous --delay 0.5

Le paramètre --delay 0.5 envoie un événement toutes les 0.5 secondes. Vous pouvez ajuster cette valeur.

✓Vérification

Si tout fonctionne correctement :

  1. Le Producteur affiche "Message sent...".
  2. Le Consommateur Spark affiche des tableaux de résultats dans la console.
  3. Le Dashboard Web (http://localhost:5000) se met à jour automatiquement avec de nouveaux graphiques.

🛠️ Lancer les Tests

Pour vérifier que tout le code est fonctionnel, vous pouvez lancer la suite de tests : 

python -m pytest tests/ -v

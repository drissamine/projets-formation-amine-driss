MediCare Exercice 4

Événements du Domaine

Domain Events Driss Amine

Contexte de l'Exercice

Cet exercice identifie et modélise les événements métier importants qui permettent la communication asynchrone entre les microservices MediCare via RabbitMQ.

10 Événements Métier Identifiés
PatientRegistered
Déclenché quand un nouveau patient est enregistré dans le système
AppointmentScheduled
Déclenché quand un patient prend un rendez-vous
AppointmentCompleted
Déclenché quand une consultation est terminée
HospitalisationStarted
Déclenché quand un patient est admis à l'hôpital
HospitalisationEnded
Déclenché quand un patient sort de l'hôpital
BedAssigned
Déclenché quand un lit est assigné à un patient
InvoiceCreated
Déclenché quand une nouvelle facture est créée
PrescriptionIssued
Déclenché quand une prescription médicale est émise
LabResultsAvailable
Déclenché quand les résultats de laboratoire sont disponibles
NotificationSent
Déclenché quand une notification est envoyée au patient

Diagramme de Séquence

Scénario : Un patient prend rendez-vous et reçoit une confirmation

Étapes du Scénario
Flux Principal
  • ① Patient POST /appointments → API Gateway
  • ② API Gateway → Appointment Service
  • ③ Validation et sauvegarde BDD
  • ④ Publication AppointmentScheduled → RabbitMQ
  • ⑤⑥ Notification Service consomme → Envoi email/SMS
  • ⑦ Réponse 201 Created → Patient
Communication Asynchrone
RabbitsMQ
  • Message broker pour découplage
  • Event: AppointmentScheduled
  • Subscribers: Notification, Billing
  • Retry en cas d'échec
  • Durabilité des messages

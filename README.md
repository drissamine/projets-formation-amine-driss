## Consultation

Les consignes et dépendances propres à chaque projet se trouvent dans ses documents et fichiers de configuration. Les fichiers `.env.example` sont des modèles de configuration.

Les deux jeux de données CSV volumineux du projet MongoDB, MLflow et DagsHub sont conservés avec Git LFS.

## Accès

Ce dépôt est privé. Seuls son propriétaire et les comptes GitHub explicitement invités peuvent le consulter.

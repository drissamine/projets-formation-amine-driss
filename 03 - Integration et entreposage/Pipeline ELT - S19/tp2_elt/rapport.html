Rapport TP2 : Approche moderne ELT

Intégration des données, orchestration et reporting avec SQLite, Python et Power BI

0 Contexte & Architecture

Rappel du cours (Chapitre 3) : L'approche ELT (Extract, Load, Transform) consiste à charger d'abord les données brutes telles quelles dans le Data Warehouse cible, puis à utiliser la puissance de calcul de ce dernier pour effectuer les transformations (nettoyage, agrégation, enrichissement).

Outils utilisés :

  • Langage & Librairies : Python 3, pandas, sqlite3
  • Data Warehouse : SQLite (fichier local data_warehouse.db)
  • Orchestration : Script Python autonome avec logging simulé (Option Task Scheduler)
  • Reporting : Microsoft Power BI Desktop

Schéma des couches de données :

Table SQLite Rôle dans le pipeline Contenu
ventes_brutes Couche Raw (Brute) Copie exacte du CSV, avec ses doublons et valeurs nulles.
ventes_clean Couche Métier (Nettoyée) Données immitées (NaN -> 0), dédupliquées, et enrichies avec la colonne total.
ventes_par_produit Couche Agrégée Chiffre d'affaires total et nombre de ventes regroupés par produit.

1 Étape 1 : Extract & Load

L'objectif de cette étape est de lire le fichier source (ventes.csv) et de le charger tel quel dans la base de données. C'est l'essence même de l'ELT : repousser la transformation après le chargement.

import pandas as pd
import sqlite3

def extract_load():
    # 1. EXTRACT
    df = pd.read_csv("ventes.csv")
    
    # 2. LOAD
    conn = sqlite3.connect("data_warehouse.db")
    df.to_sql("ventes_brutes", conn, if_exists="replace", index=False)
    conn.close()

Résultat : Les 20 lignes initiales, comprenant 2 doublons intentionnels et 1 valeur de quantité manquante, sont chargées sans altération dans ventes_brutes.

2 Étape 2 : Transform

Maintenant que les données sont dans la base (couche brute), nous effectuons les transformations en Python (via pandas) puis stockons les résultats dans de nouvelles tables cibles (couche métier).

def transform():
    conn = sqlite3.connect("data_warehouse.db")
    df = pd.read_sql("SELECT * FROM ventes_brutes", conn)
    
    # Nettoyage
    df['quantite'] = df['quantite'].fillna(0).astype(int) # NaN traités
    df = df.drop_duplicates(subset=['id']) # Doublons supprimés
    
    # Enrichissement
    df['total'] = df['quantite'] * df['prix']
    df['date_vente'] = pd.to_datetime(df['date_vente'])
    df['mois'] = df['date_vente'].dt.to_period('M').astype(str)
    
    # Agrégation et Stockage final
    df.to_sql("ventes_clean", conn, if_exists="replace", index=False)
    conn.close()

3 Étape 3 : Orchestration

Pour assurer la reproductibilité et l'automatisation de ce pipeline batch, un script d'orchestration a été mis en place. Plutôt que de lancer chaque fichier manuellement, le fichier pipeline_elt_complet.py exécute les tâches dans le bon ordre (Dépendance : T1 → T2 → T3).

  • Tolérance aux pannes : Le script incorpore une boucle de retry. En cas d'erreur de base de données, l'étape est relancée.
  • Traçabilité : Chaque exécution génère un log dans le dossier logs/ avec le temps d'exécution.
✓ Succès - Le pipeline automatisé s'exécute de bout en bout en 0.11 secondes.

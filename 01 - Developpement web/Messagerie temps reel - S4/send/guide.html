🚀 Guide de Déploiement

Application de Messagerie en Temps Réel sur Contabo VPS

📋 Vue d'Ensemble du Projet

🏗️ Architecture

  • Backend: Node.js + Express + Socket.io
  • Frontend: React + Tailwind CSS
  • Base de données: MongoDB
  • Authentification: JWT + bcrypt
  • Communication: Socket.io en temps réel

⚙️ Technologies

Node.js 18+ MongoDB 7.0 Nginx PM2 Let's Encrypt

⏱️ Durée Estimée

Total: 1h30 - 2h

  • Phase 1: 30-45 min
  • Phase 2: 20-30 min
  • Phase 3: 30-45 min
  • Phase 4: 15-20 min
  • Tests: 10-15 min
⚠️ Important: Assurez-vous d'avoir accès SSH à votre VPS Contabo avant de commencer. Si vous avez des problèmes de connexion SSH, consultez la section "Dépannage" en premier.

📋 Checklist de Déploiement

  • ✅ VPS Contabo démarré et accessible
  • ✅ Accès SSH fonctionnel
  • ✅ Clé SSH générée (optionnel mais recommandé)
  • ✅ Domaine configuré (optionnel)
  • ✅ Sauvegarde des données existantes

🔧 Vérification des Prérequis

1

Vérifier l'état du VPS

Depuis votre panel Contabo, assurez-vous que:

  • Votre VPS est dans l'état "Running"
  • Vous avez l'adresse IP de votre VPS
  • Le système d'exploitation est Ubuntu 20.04+ ou Debian 10+
2

Tester la connexion SSH

# Tester la connectivité ping votre-vps-ip # Se connecter en SSH (remplacez par votre IP) ssh root@144.91.77.138 # Si le port 22 ne fonctionne pas, essayez le port 2222 ssh -p 2222 root@144.91.77.138
3

Vérifier les ports ouverts

Assurez-vous que les ports suivants sont ouverts dans votre firewall Contabo:

  • Port 22: SSH (ou 2222)
  • Port 80: HTTP
  • Port 443: HTTPS
✅ Objectif: Une fois ces vérifications terminées, vous devriez pouvoir vous connecter à votre VPS via SSH sans problème.

🖥️ Phase 1: Configuration du VPS

Durée estimée: 30-45 minutes

1

Connexion et mise à jour du système

# Se connecter à votre VPS ssh root@votre-vps-ip # Mettre à jour le système apt update && apt upgrade -y # Installer les outils de base apt install -y curl wget git ufw htop
2

Installation de Node.js

# Ajouter le référentiel Node.js curl -fsSL https://deb.nodesource.com/setup_18.x | bash - # Installer Node.js et npm apt install -y nodejs # Vérifier l'installation node --version npm --version
3

Installation de MongoDB

# Importer la clé GPG de MongoDB wget -qO - https://www.mongodb.org/static/pgp/server-7.0.asc | apt-key add - # Ajouter le référentiel MongoDB echo "deb [ arch=amd64,arm64 ] https://repo.mongodb.org/apt/ubuntu $(lsb_release -cs)/mongodb-org/7.0 multiverse" | tee /etc/apt/sources.list.d/mongodb-org-7.0.list # Installer MongoDB apt update apt install -y mongodb-org # Démarrer et activer MongoDB systemctl start mongod systemctl enable mongod # Vérifier le statut systemctl status mongod
4

Installation de PM2

# Installer PM2 globalement npm install -g pm2 # Vérifier l'installation pm2 --version
5

Configuration du pare-feu

# Autoriser SSH (important!) ufw allow 22 # ou si vous utilisez le port 2222 ufw allow 2222 # Autoriser HTTP et HTTPS ufw allow 80 ufw allow 443 # Activer le pare-feu ufw enable # Vérifier les règles ufw status
✅ Objectif de la Phase 1: Votre VPS est maintenant prêt avec Node.js, MongoDB, PM2 et un pare-feu configuré.

⚙️ Phase 2: Configuration du Backend

Durée estimée: 20-30 minutes

1

Clonage du projet

# Se déplacer dans le répertoire home cd /home # Créer un répertoire pour votre projet mkdir messagerie-app cd messagerie-app # Cloner votre projet (remplacez par votre URL) git clone https://github.com/votre-utilisateur/votre-projet.git .
2

Installation des dépendances backend

# Installer les dépendances backend cd backend npm install # Vérifier les dépendances installées ls node_modules | head -10
3

Configuration des variables d'environnement

# Copier le fichier exemple cp .env.example .env # Éditer le fichier .env nano .env
📝 Configuration requise dans .env:
MONGODB_URI=mongodb://localhost:27017/messagerie-app JWT_SECRET=votre-secret-jwt-super-securise-ici JWT_REFRESH_SECRET=votre-refresh-secret-super-securise-ici PORT=5000 NODE_ENV=production FRONTEND_URL=http://votre-vps-ip
4

Lancement du backend avec PM2

# Démarrer l'application avec PM2 pm2 start server.js --name "messagerie-backend" # Sauvegarder la configuration PM2 pm2 save # Configurer PM2 au démarrage pm2 startup # Vérifier le statut pm2 status
5

Test du backend

# Tester l'API backend curl http://localhost:5000/api/health # Vérifier les logs pm2 logs messagerie-backend
✅ Objectif de la Phase 2: Votre backend Node.js est maintenant en cours d'exécution sur le port 5000 et géré par PM2.

🎨 Phase 3: Configuration du Frontend

Durée estimée: 30-45 minutes

1

Installation de Nginx

# Installer Nginx apt install -y nginx # Démarrer et activer Nginx systemctl start nginx systemctl enable nginx # Vérifier le statut systemctl status nginx
2

Configuration du build frontend

# Installer les dépendances frontend cd ../frontend npm install # Construire l'application React npm run build
3

Configuration Nginx reverse proxy

# Créer un fichier de configuration nano /etc/nginx/sites-available/messagerie
📝 Configuration Nginx à copier:
server { listen 80; server_name votre-vps-ip; # Frontend (React build) location / { root /home/messagerie-app/frontend/build; index index.html; try_files $uri $uri/ /index.html; } # Backend API location /api { proxy_pass http://localhost:5000; proxy_http_version 1.1; proxy_set_header Upgrade $http_upgrade; proxy_set_header Connection 'upgrade'; proxy_set_header Host $host; proxy_set_header X-Real-IP $remote_addr; proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for; proxy_set_header X-Forwarded-Proto $scheme; proxy_cache_bypass $http_upgrade; } # Socket.io location /socket.io/ { proxy_pass http://localhost:5000; proxy_http_version 1.1; proxy_set_header Upgrade $http_upgrade; proxy_set_header Connection "upgrade"; proxy_set_header Host $host; proxy_set_header X-Real-IP $remote_addr; proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for; proxy_set_header X-Forwarded-Proto $scheme; } }
4

Activation de la configuration

# Activer le site ln -s /etc/nginx/sites-available/messagerie /etc/nginx/sites-enabled/ # Tester la configuration nginx -t # Recharger Nginx systemctl reload nginx
✅ Objectif de la Phase 3: Votre frontend React est maintenant servi par Nginx avec un reverse proxy configuré pour le backend.

🔒 Phase 4: Sécurité et SSL

Durée estimée: 15-20 minutes

1

Installation de Let's Encrypt

# Installer Certbot apt install -y certbot python3-certbot-nginx
2

Obtention du certificat SSL

# Si vous avez un domaine certbot --nginx -d votre-domaine.com # Si vous utilisez seulement l'IP (moins recommandé) # Note: Let's Encrypt nécessite généralement un nom de domaine
3

Configuration HTTPS automatique

# Configurer le renouvellement automatique crontab -e
📝 Ajouter cette ligne dans crontab:
0 12 * * * /usr/bin/certbot renew --quiet
4

Sécurité supplémentaire

# Renforcer la sécurité Nginx nano /etc/nginx/nginx.conf
📝 Ajouter dans la section http:
# Sécurité Nginx server_tokens off; add_header X-Frame-Options DENY; add_header X-Content-Type-Options nosniff; add_header X-XSS-Protection "1; mode=block";
✅ Objectif de la Phase 4: Votre application est maintenant sécurisée avec HTTPS et des en-têtes de sécurité renforcés.

🔧 Guide de Dépannage

1

Problèmes SSH

❌ Erreur: "Connection timed out"
  • Vérifiez que votre VPS est démarré dans le panel Contabo
  • Vérifiez que le port 22 (ou 2222) est ouvert dans le firewall
  • Utilisez la console web depuis le panel Contabo
  • Vérifiez votre connexion internet
❌ Erreur: "Permission denied (publickey)"
  • Vérifiez votre clé SSH
  • Utilisez: ssh -i chemin/vers/votre/cle root@vps-ip
  • Générez une nouvelle clé si nécessaire
2

Problèmes MongoDB

❌ Erreur: "Failed to start mongod.service"
systemctl status mongod journalctl -xe mongod --version
  • Vérifiez l'espace disque: df -h
  • Vérifiez les permissions du répertoire /var/lib/mongodb
  • Vérifiez la configuration dans /etc/mongod.conf
3

Problèmes Nginx

❌ Erreur: "nginx: [emerg] unknown directive"
nginx -t nginx -s reload
  • Vérifiez la syntaxe de votre configuration
  • Vérifiez que les modules nécessaires sont installés
  • Vérifiez les chemins des fichiers
4

Problèmes PM2

❌ Erreur: "App [app-name] not found"
pm2 list pm2 status pm2 logs
  • Vérifiez que l'application est bien démarrée
  • Vérifiez le chemin du fichier
  • Vérifiez les permissions
5

Logique & Services

Le Service (Gestion d'État)

On utilise les Signals pour une réactivité fine. Créez src/app/services/task.service.ts.

import { Injectable, signal, computed } from '@angular/core'; import { Task } from '../models/task.model'; @Injectable({ providedIn: 'root' }) export class TaskService { // 1. État principal avec un Signal private tasksSignal = signal<Task[]>([]); // 2. Lecture seule publique tasks = this.tasksSignal.asReadonly(); // 3. Valeurs dérivées (Computed) remainingTasks = computed(() => this.tasks().filter(t => !t.completed).length); addTask(title: string) { const newTask: Task = { id: Date.now(), title, completed: false, createdAt: Date.now() }; // Mise à jour immutable du signal this.tasksSignal.update(tasks => [newTask, ...tasks]); } toggleTask(id: number) { this.tasksSignal.update(tasks => tasks.map(t => t.id === id ? { ...t, completed: !t.completed } : t) ); } }
04

Templates Modernes

Le bloc @for

Recommandé
  • Perfomance : Nouvel algorithme de réconciliation jusqu'à 90% plus rapide.
  • Syntaxe : Plus intuitif que *ngFor, plus besoin d'imports (CommonModule).
  • @empty : Gestion native des listes vides.

Fichier : src/app/components/task-list/task-list.component.html

<ul> @for (task of tasks(); track task.id) { <li> <app-task-item [task]="task" /> </li> } @empty { <li>Aucune tâche pour le moment !</li> } </ul>
Important : track est OBLIGATOIRE. Utilisez une propriété unique (id) pour aider Angular à optimiser le rendu.

Le bloc @if

Supporte enfin naturellement old else et else if sans recourir aux ng-template complexes.

Fichier : src/app/components/task-list/task-list.component.html

@if (loading()) { <loader /> } @else if (error()) { <error-msg /> } @else { <content /> }

Le bloc @switch (Bonus)

Remplace ngSwitch avec une syntaxe type JavaScript, plus lisible et avec vérification de type.

Exemple d'utilisation (dans n'importe quel template) :

@switch (status()) { @case ('DRAFT') { <span>Brouillon</span> } @case ('PUBLISHED') { <span>Publié</span> } @default { <span>Inconnu</span> } }
05

Routage & Pages

1. Création des Pages

Organisons l'application avec des composants dédiés à chaque page.

ng generate component pages/home
ng generate component pages/about

2. Configuration des Routes

Fichier : src/app/app.routes.ts

import { Routes } from '@angular/router'; import { HomeComponent } from './pages/home/home.component'; import { AboutComponent } from './pages/about/about.component'; export const routes: Routes = [ { path: '', component: HomeComponent }, { path: 'about', component: AboutComponent }, { path: '**', redirectTo: '' } // Redirection 404 ];

3. Place de rendu (Outlet)

Modifiez le composant principal pour inclure la navigation et la sortie du routeur.

Fichier : src/app/app.component.html

<nav> <a routerLink="/" routerLinkActive="active">Accueil</a> | <a routerLink="/about" routerLinkActive="active">À Propos</a> </nav> <!-- C'est ici que les pages s'afficheront --> <router-outlet />
